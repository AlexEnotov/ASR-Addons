# ASR Combat Text 0.1.6 — by AlexEnotov

Самостоятельные плавающие числа урона для Azeroth Survivors Reborn. Не требует ASR Suite, Stats или билдера. Требует игровые AzerothSurvivors и AzerothSurvivorsAPI.

Своя кнопка DMG у миникарты: ЛКМ — настройки, ПКМ — перемещение колонок. /asrtext — настройки, /asrtext edit — перемещение. При наличии ASR Suite используется общий центр /asrhub, своя кнопка скрывается.

Расположение в колонках или над врагами; размер, скорость, время, высота, минимальный отступ, объединение, иконки и сокращение чисел. Раздельные профили обычного урона, критов, лечения, полученного и периодического урона. Можно использовать общие или индивидуальные настройки. При объединении 657 ×3 означает сумму трёх попаданий, а не 657 урона за каждый удар. 0 объединения — каждое попадание отдельно.

Источник — игровой API попаданий и координат, входящий урон — боевой журнал. Нет вмешательства в модели, анимации или сохранения персонажа. Избыточное лечение вычитается. Числа движутся с заданной скоростью независимо от числа попаданий; отступ задаёт расстояние между позициями чисел без добавления высоты текста или иконок. Малые значения допускают их частичное перекрытие.

Выключение восстанавливает ранее работавший текст: стандартный или SurvivorUI. Состояние сохраняется до захвата, возвращается при выключении и выходе. Другие интерфейсные элементы не меняются. Для иных сторонних замен доступны адаптеры комплекса; без адаптера чужие панели не трогаются.

Сохранение ASRCombatTextDB независимо от комплекса. Старые настройки Suite мигрируют один раз. Тесты: node ASRCombatText/tests/run.cjs (включая работу без Suite и восстановление стороннего режима).

Минимальный отступ больше нуля включает последовательный показ из очереди: новые числа ждут свободного места, не ускоряя существующие и не смещая начало колонки. При плотном потоке возможна задержка отображения. Отступ 0 разрешает наложение. Время показа отсчитывается с появления числа; достигнув высоты движения, оно освобождает место следующему.
