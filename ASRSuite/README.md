# ASR Suite 0.4.3 — by AlexEnotov

Необязательный общий центр настроек ASR. Собственных боевых чисел больше не содержит: это отдельный ASR Combat Text.

## Состав

- ASR Advisor — отдельный билдер, /asr.
- ASR Stats — отдельные характеристики, /asrstats config.
- ASR Combat Text — самостоятельный текст урона, /asrtext, своя кнопка DMG у миникарты.
- ASR Suite — общие настройки, совместимость и режим перемещения, /asrhub.

Можно установить любой нужный набор. Каждый функциональный модуль работает без комплекса и других наших аддонов. При наличии Suite кнопка DMG скрывается, остаётся общая кнопка ASR. Старые настройки текста из Suite переносятся автоматически один раз, дальнейшие изменения не затираются.

## Управление

У миникарты ЛКМ — настройки, ПКМ — Изменить интерфейс. Слева только разделы: Общие, Текст урона, Stats, Билдер, Совместимость. Типы урона выбираются внутри раздела Текст урона. Активная вкладка выделена. Неустановленные модули показывают заглушку без неработающих настроек.

У каждого модуля есть Включён. Выключение билдера скрывает все рекомендации (карточки, переброс, пропуск, изгнание) и трекер, но не удаляет билды. Скрытие только трекера — отдельная настройка.

Закрепить все панели блокирует обычное перемещение/размеры трекеров. Окна настроек остаются доступными. Изменить интерфейс временно разрешает перемещение Stats, трекера билдера и областей чисел. Готово завершает режим и возвращает блокировки. Позиции сохраняются.

## Профили и прозрачность

Настройки размера, скорости, времени, высоты, объединения, минимального зазора, иконок и кратких чисел наследуются из общих. Галочка своего профиля включает независимые значения типа; выключение галочки их не удаляет.

Отдельно: фон настроек, фон трекеров и непрозрачность чисел. У модулей есть независимые переключатели своих фонов меню и трекера.

## Совместимость и восстановление

Источники текста: как было до ASR, стандартный, ASR Combat Text, SurvivorUI (если доступен). Выбор заменяет только соответствующий элемент. Выключение ASR Combat Text восстанавливает ранее активный режим, включая сторонний текст, а не обязательно стандартный. При выходе/перезагрузке прежние значения также восстанавливаются.

Будущие модули (например, вид группы) могут регистрировать источники через RegisterDisplaySource. Обработчик включения может вернуть функцию восстановления сохранённого стороннего состояния; выключение вызывает её. Чужие панели без адаптера не скрываются и не переписываются.

## Расширение

RegisterSettingsPage(id,title,build,draw,parent) — страница модуля или внутренняя вкладка. RegisterPanel — участие в общем режиме перемещения и выключении. Сохранения модулей отдельные; настройки комплекса не изменяют билды. Проверки: node ASRSuite/tests/run.cjs. Визуальную проверку в игре выполняет пользователь.
