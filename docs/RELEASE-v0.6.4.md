# ASR Addons v0.6.4

## ASR Advisor

- Added eight Cataclysm jewelry items and base effects for 237 spell amulets
  across all twelve classes, including Mind Sear.
- Eligible legendary and epic upgrades for learned spells have first priority.
  With an open spell slot, an eligible new spell comes before rare or
  lower-rarity upgrades. Card hints show Build or Any based on the winning choice.
- Any labels fit on one line in the planner and catalogue.
- Eye of the Tempest keeps the last description received from the game after
  you equip it in a run.

## Tracker appearance

Customize each tracker in **ASR Suite → Appearance**. Advisor, Stats, Endless,
Loot and Party now offer the original frame, a compact tooltip-style frame
inspired by Run Info, and a borderless mode.

- Thin and borderless layouts use tighter spacing to save vertical space.
- Magnetic docking follows each frame's visible bounds.
- Chat's existing frame styles are also available on the same Suite page.
- Without Suite, add `frame stone`, `frame thin` or `frame none` to the addon's
  usual command. For example, `/asrstats frame thin`.

Eight individual addon ZIPs and the complete **ASR-All-v0.6.4.zip** pack are
available below. Extract the chosen addon folders directly into
`Interface/AddOns` and restart the game.
